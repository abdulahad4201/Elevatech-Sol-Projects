# JoyNow – QA Testing Project

This repository showcases my QA testing work on **JoyNow**, a subscription-based wellness platform that allows users to access guided meditation content while providing subscription management, payment handling, and creator referral features.

---

## 📌 Project Overview

* **Project Name:** JoyNow
* **Project Type:** Web Application
* **Testing Type:** Manual Testing
* **Focus Area:** Functional Testing, Subscription Management & User Workflows

---

## 🧪 Testing Scope

During this project, I performed testing across multiple modules, including:

* User Authentication (Sign In, Sign Up & Password Recovery)
* Subscription Management
* Subscription Cancellation Flow
* Refund Eligibility & Processing
* Payment Workflows
* Creator Referral & Payout Features
* User Profile Management
* Email & Notification Verification
* Admin Features
* Functional & UI Testing

---

## 🐞 QA Activities

* Executed functional testing for user and subscription workflows
* Verified subscription cancellation and refund scenarios
* Tested payment-related functionality and user account behavior
* Validated form inputs, business rules, and error handling
* Identified, documented, and reported functional and UI defects
* Performed regression testing after issue resolution
